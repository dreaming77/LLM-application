## 总体概述

1. 文档加载：对标题的加粗格式保留和处理表格内容。
2. 文本分割：1）规则切分，定制结构层级正则表达式，按章、节、条逐级按行处理。2）语义切分，通过Bert模型提取句子的语义向量，计算句子之间的语义相似度考虑是否合并。最终将文本分割为结构化的内容块。
3.  使用RAG Fusion技术来增加相关文本块的召回率。

> RAG Fusion核心思想是通过**多视角检索与信息融合**。传统 RAG 通常仅基于用户 query 进行一次检索，返回最相关的少数文档片段。而 RAG Fusion 则通过以下步骤优化这一过程：
>
> 1. **多query生成**：对原始用户 query 进行变体扩展（如同义词替换、句式改写、角度转换等），生成多个语义相似但视角略有差异的查询语句。
>    - 例如，对于 query “如何预防感冒”，可生成 “预防感冒的有效方法”“怎样避免患上感冒” 等变体。
> 2. **多源检索**：将这些变体 query 分别输入检索系统，获取多组相关文档片段。
> 3. **信息融合**：通过打分、去重、排序等策略，将多组检索结果融合为一个更全面的上下文集合，确保覆盖不同维度的相关信息。
> 4. **生成优化**：基于融合后的上下文，让大模型生成最终回答，减少因单一检索结果偏差导致的信息遗漏或错误。

4. RAG_Chain：初始化LLM组件——>配置RAG Fusion检索器（创建查询链、创建RAG Fusion检索器）——>创建优化后的Langchain问答链
5. 使用streamlit做个简单的UI

> 语义边界动态切分方法介绍——————该方法采用规则切分和语义切分相结合的方式
> 
> 规则切分：利用法律文本特有的结构（如 "第一条"、条款编号、逻辑连接词）进行初步分割
> 语义切分：通过BERT模型计算句子间语义相似度，动态调整切分边界
>
